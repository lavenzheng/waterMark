# 飞书多维表格水印插件

一个用于飞书多维表格的侧边栏插件，可以为图片添加水印并保存到指定字段。

## ✨ 功能特性

- 🖼️ **图片水印处理**：支持为图片添加自定义水印
- 📝 **多种水印来源**：支持自定义文本或从表格字段获取水印内容
- 🎨 **丰富的样式设置**：字体、大小、颜色、透明度、位置等
- 💾 **智能保存**：自动保存到指定的附件字段
- ⚡ **性能优化**：图片缓存、防抖处理、异步操作
- 🌍 **国际化支持**：支持中文、英文、日文

## 🛠️ 技术栈

- **Vue 3** - 使用 Composition API
- **Element Plus** - UI组件库
- **TypeScript** - 类型安全
- **Vite** - 构建工具
- **@lark-base-open/js-sdk** - 飞书多维表格SDK

## 📝 使用说明

1. **选择图片**：在飞书多维表格中选择包含图片的单元格
2. **配置水印**：设置水印文本、样式、位置等参数
3. **选择目标字段**：选择要保存水印图片的附件字段
4. **保存图片**：点击保存按钮，水印图片将保存到指定字段
